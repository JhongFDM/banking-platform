# Playwright QA Suite

This folder hosts the Playwright QA automation set.

Structure overview:
1. tests/bdd/features for Gherkin features.
2. tests/bdd/steps for step definitions.
3. tests/ui for page objects and UI helpers.
4. tests/api for API-focused tests.
5. support for fixtures, data, and shared utilities.
6. generated/bdd-specs for playwright-bdd generated specs.
7. artifacts for test reports and run results.
8. config for Playwright and TypeScript config files.
